# Contributing

Thanks for helping make this the best map of agent harnesses.

## What belongs here

A resource specifically about **agent harnesses** — the runtime scaffolding around an LLM: agent frameworks, coding-agent harnesses, the loop/reasoning/orchestration patterns, papers on agent architecture, benchmarks, standards, and sandboxing infra. Not generic LLM/prompting content unless it's directly about building agents.

## How to add something

1. Fork and edit `README.md`.
2. Put the entry in the right section, keeping the existing format (stars-descending for frameworks, newest-first within paper groups).
3. One line per entry. Say what it *is* and what's *distinctive about its harness/loop design* — no marketing copy.
4. Verify the link works and points at the canonical source (GitHub repo, arXiv abstract page, official docs/leaderboard).
5. Open a PR with a one-line reason.

## Bar for inclusion

- **Real and locatable** — working URL, not a vague mention.
- **Specific to agent harnesses** — the loop, tool execution, orchestration, scaffolding, agent architecture.
- **Not a duplicate** — many projects rename (Phidata → Agno, OpenDevin → OpenHands, Swarm → Agents SDK). Check first.

For framework entries include where known: stars (order-of-magnitude is fine), language, license, distinctive design. Flag closed-source projects as such. Correcting stale status (maintenance mode, deprecations, license type) is also welcome.
